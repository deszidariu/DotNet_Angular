COMENZILE RULATE PENTRU CONECTAREA LA GITHUB
==============================================

1. Inițializarea repository-ului Git local:
   git init

2. Adăugarea GitHub repository ca remote:
   git remote add origin https://github.com/deszidariu/DotNet_Angular.git

3. Verificarea că remote-ul a fost adăugat (verificare):
   git remote -v

4. (OPȚIONAL) Pentru a descărca conținutul din GitHub:
   git fetch origin
   git checkout -b main origin/main

5. (OPȚIONAL) SAU pentru a face pull direct:
   git pull origin

NOTĂ: Comenzile 4 și 5 sunt pentru a descărca efectiv fișierele din GitHub.
      Trebuie rulat una din ele după ce ai rulat comenzile 1-3.

COMENZILE PENTRU PUSH LA GITHUB
================================

6. Adauga toate fișierele la staging:
   git add .

7. Face commit cu mesajul "Initial commit":
   git commit -m "Initial commit"

8. Redenumește branch-ul la "main":
   git branch -M main

9. Face push la GitHub:
   git push -u origin main

Odată ce execuți aceste comenzi (6-9), codul din folderul tău va fi uploaded pe GitHub!
